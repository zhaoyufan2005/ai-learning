🎯 一段话讲清三者关系

核心逻辑

Agent（智能体） 是行动主体：它有目标、会规划、能决策"接下来做什么"。

上下文（Context） 是 Agent 的工作台：Agent 的每一次思考都发生在这张台面上——台面上摊着的东西（对话历史、系统提示、检索到的资料、工具返回结果）就是它此刻知道的全部。台面有固定大小（上下文窗口），堆满就得清理。

Skill（技能包） 是放在台边工具架上的操作手册：平时只露出"书名和简介"（描述），几乎不占台面；当任务匹配时，Agent 把它取下来摊开在工作台上（加载 SKILL.md 全文），照着手册里写好的流程和规范干活。

一句话串联：Agent 坐在上下文这张工作台前，遇到熟悉的活儿，就从架上取下对应的 Skill 摊开照做——Skill 通过上下文发挥作用，上下文通过 Skill 获得结构化的经验。

🏭 一个贯穿的类比：维修车间

把整套系统想象成一间维修车间：

车间里系统里关键性质
老师傅（会判断、会拆解任务） Agent 决策者；能力来自底座模型
工作台（台面上摆什么就知道什么） 上下文 唯一信息来源；面积固定（窗口）；旧物堆多了要清
墙上工具架上的操作手册 Skill 平时只见书脊（描述）；用时取下摊开（加载全文）
台上的电动工具（扳手、检测仪） Tool / MCP 真正的"手脚"；Skill 常指挥该用哪件
师傅练出的手感（改不动的本能） 微调（Fine-tuning） 写入参数；对照：Skill 是外挂手册
💡 类比的推论
  • 台面（上下文）是瓶颈也是命脉：手册再好，摊不开（窗口不够）就发挥不了；台面被杂物占满（上下文污染），手册摊开了也没地方看。
  • 手册（Skill）解决的是"稳定性"而非"能力"：老师傅本来就会修车，手册保证他每次都按同一套规范修——Skill 规范的是 Agent 怎么做，不是赋予它新本能。
  • 架子越大越要克制：手册多了，只看书脊也占地方（常驻描述）；描述写得含糊，师傅会拿错手册（误触发/漏触发）。

🔄 三者如何协作：一次完整执行

以本仓库真实发生的事情为例——用户输入"学习概念：Agent"后发生了什么：

用户请求："学习概念：Agent" │ ▼ ① 请求写入【上下文工作台】（与系统提示、对话历史并排摊开） │ ▼ ② 【Agent】环视台面：这是一个"生成学习资料"的任务 │ 同时扫到台边架上各 Skill 的书脊（描述，仅几百 token 常驻） │ ▼ ③ 匹配 concept-learner：从架上取下，摊开到台面 │ （SKILL.md 全文进入上下文；未匹配的 Skill 依旧收着） │ ▼ ④ Agent 按手册干活：解析概念 → 组织五段结构 → 调用写作能力 │ （产出过程中，手册内容+已写内容都持续占据台面） │ ▼ ⑤ 产出 agent.html → 工具调用把文件路径等结果放回台面 → 汇报用户 │ ▼ ⑥ 台面留痕：下一轮对话中，Agent 依然"看得见"这次任务的全部经过

注意两个要点：Skill 全程经由上下文生效（第③步），它不绕开工作台直接"改装" Agent；Agent 对台面内容自主取舍（第②步决定用哪个 Skill、第④步决定怎么执行流程）——这正是 Agent 区别于固定流程编排的地方。

⚖️ 常见问题与辨析

Q1：Skill 和上下文是什么关系——是"加载进去"还是"并行工作"？

是加载进去。Skill 的唯一生效通道就是上下文：所谓"启用 Skill"，就是把 SKILL.md 的文本注入上下文窗口，让 Agent 在后续思考中读到它。因此 Skill 受上下文的一切规律约束——占 token、可能被截断、与台面上其他内容竞争注意力。

Q2：Agent、上下文、Skill，谁是"必需品"？

上下文是绝对必需（没有上下文，模型连"看到任务"都做不到）。Agent 和 Skill 都是可选的增强：不拆任务不规划，一个普通对话也能完成任务（那就不是 Agent 形态）；没有 Skill，Agent 靠通用能力也能做，只是输出质量像"临场发挥"而非"按手册办事"。三者齐备 = 既自主又规范。

Q3：把所有 Skill 全文常驻上下文，不是更保险吗？

恰恰相反。这正是"渐进式披露"要避免的：几十份手册全文摊在台面上，等于把工作台变成仓库——关键指令被淹没（上下文污染）、有效注意力被稀释（Lost in the Middle）、成本按 token 计费陡增。工作台的价值在于"此刻相关"，而非"应有尽有"。

Q4：三者的"容量观"如何统一？

  • 上下文是稀缺资源 → 用检索（RAG）决定什么上台面；
  • Skill 架理论无限 → 但描述质量决定路由准确性 → 贵精不贵多；
  • Agent的规划能力 → 决定台面物料的进出节奏（清理、摘要、外存），是长任务的"台面管家"。
